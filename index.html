选择等价外在形式

    📥 导入记号定义

    概述：你的代码需定义一个名为 Notation 的对象，由 6 个必备函数和 1 个可选函数组成。函数之间通过"内部表示"互相传值——内部表示可以是任意 JavaScript 值（数组、对象、数字、字符串等），由你自行决定结构。

    必备函数
    · parse(input: string): obj | null — 将用户输入的表观字符串转为内部表示。无法解析时返回 null。
    · format(obj): string — 将内部表示转为可读字符串，用于树节点显示。
    · isSuccessor(obj): boolean — 判断是否为后继节点（不可再展开的"终点"，例如 PrSS 中的 (1)）。
    · generateLimit(k: number): obj — 返回记号极限的基本列第 k 项（k≥1）。这是"从无到有"的入口，框架首次展开 root 节点时调用。
    · expand(obj, n: number): obj | null — 对非后继节点 obj 取其基本列的第 n 项（n≥1）。展开方向：返回值应在序结构上严格小于 obj（向 successor 方向递减）。若 obj 无法以 n 展开（如 successor 或非法参数），返回 null。
    · compare(a, b): -1 | 0 | 1 — 比较两个内部表示的严格全序。要求自反、反对称、传递；不一致会导致排序错误与树结构异常。

    可选函数
    · equivalentForms(matrix): { default: string, forms: { [name]: { display, parse } } } — 定义等价外在形式。框架会把 default 指定的形式作为默认显示；用户可点击工具栏"🔄 等价形式"切换显示；"展开到"输入框也会按当前选中的形式去 parse。
      – display(obj): string — 内部表示 → 该形式下的可读字符串
      – parse(str): obj | null — 该形式下的字符串 → 内部表示
      – 注意：合法但 falsy 的返回值（如 0、false、''）会被框架正确接受；只有 null/undefined 才视为"不合法"。

    约束与建议
    · 内部表示可以是任意类型。但截断功能仅在内部表示为数组、且数组的任意前缀仍是合法的标准式时才可用。
    · 框架内置时间截断机制：单次展开超过 timeoutMs（默认 5000ms，可在工具栏 ⏱ 按钮调整）会被强制中止，避免某些记号无限延伸导致浏览器卡死。
    · 不要在 parse/expand 等函数中执行网络请求或 setTimeout 等异步操作——框架按同步函数调用。
    · "自动展开到目标"功能通过快照实现回滚。快照采用浅拷贝策略——保留 matrix 引用而非深拷贝，因此支持 Map/Set/Date/BigInt 等任意类型；前提是你的 expand/parse 等函数不会原地修改已注册节点的 matrix 对象（应该总是返回新对象）。

    展开行为说明：框架对非后继节点 N 调用 expand(N, k)（k 从 1 开始递增）直到返回值满足"未出现过的、且大于下一个兄弟节点"的条件，将首次满足的返回值作为 N 的子节点添加。之后会自动延伸：对刚添加的子节点继续尝试 expand(子节点, 1..100)，找到"未出现过的、比当前树中已存在的更大值更小"的新节点继续添加，直至达到 successor 或找不到新值。
